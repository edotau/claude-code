# Security Policy

## Reporting a vulnerability

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/edotau/claude-code/security/advisories/new) — not in a public
issue or pull request. Include the affected command, hook or file, steps to reproduce, and the impact.

Never include real credentials, tokens or vault contents in a report; redact them.

## Supported versions

Only the latest `main` is supported; fixes land there.
