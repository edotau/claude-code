# Knowledge — long-term, near-rules notes

Durable lessons promoted out of `~/.claude/memory/` that are worth keeping in git but are not (yet) rules:
`docs/knowledge/<topic>.md` for cross-repo knowledge, `docs/knowledge/<repo>/<topic>.md` for one repo.

- Ladder: transcript → `memory/` (harvest) → `docs/knowledge/` (`claude-code memory promote`, reviewed) → `rules/`
  (enforced).
- Tracked and public: never promote private project names, paths or credentials here.
- Not loaded automatically; the memory catalog lists what exists, agents read on demand.
